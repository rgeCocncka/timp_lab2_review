Требования к программе:



R1: Проверяются все элементы, от первого и до последнего.

R2: В список вносятся элементы, для которых одновременно выполняется условие: оплачены, но не доставлены.

R3: Данные заказов не должны изменяться при совершении проверки.



Ожидаемые и фактические результаты:
**T01**, Вход \[{true, false, true, true}, {false, false, true, false}], Ожидаемый результат: \[0, 3], Фактический результат: \[0]

**T02,** Вход \[{true}, {false}], Ожидаемый результат: \[0], Фактический результат: \[]

**T03,** Вход \[{false, false}, {false, true}], Ожидаемый результат: \[], Фактический результат: \[0]

**T04,** Вход \[], Ожидаемый результат: \[], Фактический результат: \[]

**T05,** Вход \[{true, false}, {false, true}] и вывод значения первого элемента второго массива, Ожидаемый результат: False, Фактический результат: True



Ошибки в программе возникают следующие:
R01: **Пропущен последний элемент:** Последний проверяемый элемент не проверяется.

R02: **Неверное условие отбора:** В реализованном условии отбора элементов учитывается хотя бы один из рассматриваемых параметров, а не обязательно оба.

R03: **Изменение входных данных:** После отбора элементов изменяется значение флага shipped на true, чего быть не должно.
