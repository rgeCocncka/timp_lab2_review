# Вариант 16 — Список заказов для отгрузки

Работнику склада нужен список номеров оплаченных и ещё не отправленных заказов.

paid и shipped одинаковой длины. Вернуть индексы записей с paid == true и shipped == false в исходном порядке. Это только просмотр: не менять флаги и не отмечать заказы отправленными.

Исходник ReviewTask.cs намеренно содержит ошибки.
Не меняйте ожидаемые значения в Program.cs ради успешного запуска.

Запуск: dotnet run --project ReviewLab.csproj

- T01: Обычный; ожидается [0,3].
- T02: Один готовый; ожидается [0].
- T03: Неоплаченный; ожидается [].
- T04: Пустой; ожидается [].
- T05: Флаги сохранены; ожидается [False].
